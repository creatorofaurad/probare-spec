# Probare SMT-LIB2 Obligation & Refutation Schema

This document specifies the exact formal mathematical obligation semantics generated by **Probare** from LLVM Intermediate Representation (IR).

---

## 1. The Core Refutation Query

For each potentially undefined instruction $I$ in a basic block $B_I$, Probare generates a single negated safety query:

$$\Phi_I = \mathrm{PC}(B_I) \wedge \neg\,\mathrm{Def}(I)$$

Where:
- $\mathrm{PC}(B_I)$ is the Path Condition scoping reachability to block $B_I$:
  $$\mathrm{PC}(B) = \bigvee_{\pi \in \Pi(B)} \bigwedge_{c \in \pi} c$$
- $\mathrm{Def}(I)$ is the bit-precise Definedness Predicate for instruction $I$.

### Consensus Gate Invariant:
$$\text{Lowering Permitted} \iff \forall I \in \text{Loop}: \bigwedge_{s \in \text{Pantheon}} \mathrm{Verdict}(s, \Phi_I) = \mathtt{unsat}$$

If any solver returns $\mathtt{sat}$, compilation halts immediately, and the model is extracted as a concrete counterexample witness.

## 2. Definedness Conditions by Instruction Kind

| Instruction Kind | Definedness Predicate $\mathrm{Def}(I)$ | SMT-LIB2 Invariant |
| :--- | :--- | :--- |
| `add nsw` / `sub nsw` | No signed overflow | `(= (bvsadd lhs rhs) (sign_extend ...))` |
| `add nuw` / `sub nuw` | No unsigned overflow | `(= (bvuadd lhs rhs) (zero_extend ...))` |
| `sdiv`, `srem` | Non-zero divisor $\wedge$ non-overflow | `(and (distinct rhs 0) (not (and (= lhs INT_MIN) (= rhs -1))))` |
| `udiv`, `urem` | Non-zero divisor | `(distinct rhs 0)` |
| `shl`, `lshr`, `ashr` | Shift amount within bit width range | `(bvult shift_amount bit_width)` |
| `load`, `store` | Spatial bounds & initialization | `(bvule (bvadd offset size) object_capacity) \wedge \text{Init}(ptr)` |
| `unreachable` | Dead path invariant | `(not PC(B_I))` |

## 3. Disjoint Monolithic Memory Model (QF_ABV)

Address space is formalized as a monolithic array:
$$\mathcal{M} : \mathrm{Array}(\mathrm{BitVec}_{64}, \mathrm{BitVec}_8)$$
With a parallel byte-initialization bitmap:
$$\mathcal{M}_{\text{init}} : \mathrm{Array}(\mathrm{BitVec}_{64}, \mathrm{BitVec}_1)$$

### Non-Aliasing Pointer Construction:
Pointers are structural concatenations:
$$p = \mathrm{Concat}(\mathrm{obj\_id}_{32}, \mathrm{offset}_{32})$$

For distinct symbolic pointer parameters $p_1, p_2$:
$$p_1 \neq p_2 \implies (p_1 + \text{size} \le p_2) \lor (p_2 + \text{size} \le p_1)$$

## 4. Hardware Translation Validation Claim

For loop bodies lowered to AVX-512 EVEX predicated machine code, Probare proves per-lane semantic equivalence:

$$\forall i \in [0, \text{LANES}-1]: \begin{cases} k[i] = 1 \implies v_{\mathrm{evex}}[i] = v_{\mathrm{scalar}}[i] \\ k[i] = 0 \implies v_{\mathrm{evex}}[i] = \mathit{old}[i] \end{cases}$$

Under merge-masking ($\{k_1\}$), masked-off vector lanes are mathematically guaranteed to preserve prior accumulator state and suppress out-of-bounds memory faults at the hardware load/store unit.
